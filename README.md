# LogiPallet — Landing estilo Apple

Landing de **venta y renta de tarimas** con tipografía del sistema, navegación con blur, secciones alternas claro/oscuro, galería e ilustraciones locales en `images/` (funcionan sin internet).

## Cómo verla

Abre `index.html` en el navegador o sirve la carpeta con un servidor local:

```bash
cd /Users/anderson/Documents/apple-landing
python3 -m http.server 8080
```

Luego visita [http://localhost:8080](http://localhost:8080).

## Archivos

- `index.html` — estructura y contenido
- `styles.css` — estilos
- `script.js` — nav, menú móvil y reveal al scroll
